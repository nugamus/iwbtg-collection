# Client UI art: credits

Every file in this folder is here for the same reason: the client draws it when no game is loaded, its source is credited below, and the user's decision of 2026-11-26 (#1608) allows it. A loaded package's own art always comes from the package; this folder holds no other extracted game art.

`cherry.png` is the delicious fruit, two frames of 21 x 24: the cherry sprite of the IWBTG fangame engine, the same in most fangames. This copy comes from **I wanna Little Trap** by **waka** (https://delicious-fruit.com/game/21365), taken from its conversion to our package format, like the showcase's Kid. The delicious fruit is from **I Wanna Be The Guy** by **Kayin**.

The client draws it where no game is loaded (the main menu's centrepiece) and where a loaded game has no `cherry` sprite of its own (the pause menu's selector, the loading card).

It is game content, not covered by the repository's code or documentation licenses. It is here, credited, by the user's decision of 2026-11-26 (#1608): the UI uses the real delicious fruit, not a remake. Its owners can have it removed.
