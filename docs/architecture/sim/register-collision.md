# Sim register: Collision

Part of the [sim register](../sim.md#register).

The **Impact** column is the fidelity tier ([fidelity impact tiers](../../plans/fidelity-tiers.md)): T1 can change a ranked run, T2 only off-ranked paths or visuals and sound, T3 only a probe column, T? is not judged. T1 blocks phase 3; T2 and T3 move to the port (rule on the tier page). The **Claim** column names the stable research id the row implements, from `research/specs/engines/gm8/runner/collision.md` (claims `COL-NNN`), indexed by `research/specs/INDEX.md`. The register id stays the client-side key. — marks a row with no matching GM8 claim, with the reason. `scripts/test_spec_claims.py` fails on a cited id that is not in [`claim-ids.txt`](claim-ids.txt).
