# The client: HUD

Part of [the client](../client.md).

HUD (`hud/`, `HudPlugin`; docs/product.md, In-game display; artboards `Hud169`, `Hud43`, `Hud219`, `HudSmall`): three columns, the live leaderboard left, the game centre, run info right. `hud::layout::compute` is pure (unit-tested at every artboard size) and works in logical px (the artboards' CSS px; physical px divided by the display scaling). The game fills the area's height unless the columns would get less than 204 px (left) and 180 px (right), then it shrinks (`Hud43`: 0.8x at 1024x768). A window of 960x540 or less in either direction is small: the columns keep 124 px each, the leaderboard shows rank and avatar plus your time, run info stacks under the timer and the input display hides. Spare room is split evenly; each column stops at 360 px (times the UI scale) and the rest is backdrop (`Hud219`). Density: full from 240 px per column (at the UI scale), else compact. The UI scale (75 to 150%, Ctrl+= and Ctrl+-, `--ui-scale`) scales only the panels (`UiScale`), never the game: when a column is too narrow for the panel at that scale the panel scale stops at what fits (`Layout::content`). Shift+Tab hides the whole HUD and gives the game the whole area; the HUD always starts shown. The panels (`hud/panels.rs`) draw on a camera of their own (order 10, UI only) and are rebuilt only when their density or width changes; the leaderboard is 92% of its column, 7% from the game, run info 84%, 9% from it. A box shadow around the game (`0 0 60px` at 60% black) is drawn by the backdrop's camera, under the game. Until the live leaderboard lands, it is a frame with placeholders: skeleton rows with the no-avatar mark and your row at #1 with the run's time. Run info (`hud/run_info.rs`, #37; `RunInfo.dc.html`): `read` fills the `RunInfo` resource every frame from the sim and `show` writes it into the panel; the panel is rebuilt only when its `Look` changes (ranking, mods, toggles, bound extra actions). From top: a `Paused · timer running` line while `hud::run_info::Paused` is set (the pause menu, #479, sets it); the mod row, only for an unranked run (the amber Unranked pill: Play original, or a mod that is not ranked) or when mods are on (24 px sheared pills with the codes); a plain ranked run shows nothing there. The timer is `Sim::ranked_ticks` as `m:ss` with the hundredths smaller and in the soft colour. Deaths is the death counter (`global.death`, so a run from a save starts with its deaths); Stage is `stages_done + 1` of the map's stage splits + 1; This stage counts deaths since the stage began and starts again at a new stage or a retry (`StageDeaths`). The input display draws the four arrows and Jump, Shoot, Restart from the frame the last tick took (`input::Collector::last`), lit white with an accent bar while held or pressed; Extra 1-4 appear when the player has bound them. Small windows stack the stats under the timer and hide the input display. Every element toggles on its own (`[hud.show]`, `--hud-show`, `--hud-hide` with comma-separated names); `leaderboard` hides the left panel. Hidden flags for screenshot checks: `--hud-preview-held right,jump` and `--hud-preview-paused`.
