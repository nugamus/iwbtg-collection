# The client: Session summary

Part of [the client](../client.md).

Session summary (`session/`, `SessionPlugin`, #1624; docs/product.md, Two ways to play each game; m5 `A8_Session`, `A9_SessionFinished`, `Session.dc.html`): leaving a Classic game shows what the session did instead of the Time Attack [results](results.md): no placement, no splits.

- **When.** The pause menu's Back to the shelf in Classic (`pause::act` calls `session::open`), and a Classic run's ending: `open_on_finish` (in `Playing`) opens it once the open session's end fired (`stats::SessionLog::finished`). The results page does not open for a Classic run (`results::open` returns early for `PlayMode::Original`). It is the run screen `RunScreen::Session` ([shell](shell.md)): the sim does not tick, the game camera is off, the HUD is suspended and the backdrop takes the results' dim (`cover`, as on results); the page draws on its own UI camera (order 20). A Classic run sets the toolbar mode to Classic, so the primary button is violet.
- **Page.** Laid out at 1920x1080 and scaled to the window. Header: the game's title, the CLASSIC pill, the date and the session's start and end times. The hero: `This session` (or `Last session · the ending` with the violet Finished pill and the fruit) and the session's time (`h:mm:ss`). Four facts: Deaths (and the game's Classic deaths), then, before the ending, Got to (the last room entered; `N new` in violet), Save points (and the last one's room) and Rooms (distinct rooms entered, `N new`); after it, Time played (the game's Classic total), Rooms and Finished (how often). The player card (results variant) top right. Below: the three rooms with the most deaths this session (bars against the most, the first violet) and the session's timeline: a red tick per death and a violet diamond per save, placed by session tick, the last eight saves labelled with their room, the start and end times under it, and the note.
- **Buttons.** Back to the shelf (Escape) leaves the run (`shell::leave`). The primary (Enter): Continue playing goes back to the game (`Playing`, the run was never closed); after the ending, Play again starts a new run (`retry::request`). Keys pressed on the page are dropped.
- **Data.** `page::Summary::read`: the open session (`Stats::open_session`, #1623) and the book's Classic numbers (`Book::game_mode`, #1619).
- **Not built yet.** The route line (#1656), Save replay, the Classic player card (m5 A10, group 16), the game icon (group 5), the count-up and bar animations, and the session panel beside a Classic run (A7, #1624).
- **Preview.** `--session-preview <playing|finished>` (hidden) opens the page at sim tick 25 for screenshot checks.
