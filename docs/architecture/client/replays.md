# The client: Replays

Part of [the client](../client.md).

Replays (`replays.rs`, `ReplaysPlugin`, #476): every run is recorded as an `.iwbr` replay ([replay format](../replay.md#replay-file-iwbr)) in the data area of Storage, for the replay viewer and upload (M7). A run is one sim: the client's start, and each quick-retry or auto-retry. `view::tick` hands the `Recorder` each tick's input frame and splits; the header comes from the sim's options and the package (id, `gameplay_hash` from `package::open`, `engine_rev`, seed, start: `NewGame`, or `FromSave` with the postcard bytes of the resumed save slot, play mode, `Sim::map_id`, the run's mods, `iwbtg-client <version>`). Checkpoints are taken every 500 ticks. The file is written when the run's timer ends (a ranked run's replay stops there; Play original keeps recording into the same file, so one Play original session until a retry is one replay), when a retry starts the next run (`replays::reset`, before the new sim replaces the old) and when the window closes (`Last`, after Bevy's exit check, while the sim is still there). Each write prints `replay: <path> (<ticks> ticks, <bytes> bytes) hash <final state hash>`; `iwbtg replay verify <pkg> <file>` prints the same hash. Names are `replays/<game id>/<unix seconds>-<n>.iwbr`, listed oldest first in `replays/index.txt` (browser storage cannot list its entries); natively every replay is kept, on the web only the newest 50 (an hour's replay is a few KB) plus the ones a stats board points at. A cleared run on a stats board points at its replay. Web pruning (#607, `replays::to_remove`) runs when a new replay is first listed: it reads `stats.toml` and, while more than 50 are listed, removes first the oldest replays no board run points at, then the oldest replays of top runs that are not a PB. A board's PB replay and the replay just written are never removed, so when the boards' top runs alone exceed 50, the older top runs lose their replays (their `replay` entry then names a missing file); more than 50 stay only when there are 50 or more PB replays. An unreadable `stats.toml` removes nothing that time. Seeds: every run (and every retry) draws a new random seed (`replays::fresh_seed`: the OS-keyed `RandomState` and the clock natively, `Math.random` on the web), as the originals randomize; a `--screenshot` check keeps seed 0 and records nothing. `--ranked` plays the ranked (stripped) mode: always a new game, never the save file (it implies `--no-save-file`); without it the client plays Play original.
