# The client: Mods

Part of [the client](../client.md).

Mods (`mods.rs`, `ModsPlugin`, #35): `--mods <codes>` (`SD`, `SL`, `FA`; codes joined by `,` or `+`) picks the run's mods from `iwbtg_sim::mods::MODS`, and the client prints the play mode and mods on start: `Play original (unranked), mods: SD` without `--ranked` (Play original is never ranked), `Play ranked, mods: SD (ranked)` (or `unranked: <mod name>`) with it (#606). Sudden Death, Slow motion and Frame advance are built (the last two act on the clock, [practice assists](practice.md)); any other code is refused as not built yet (#550, save states #39). Sudden Death: after each tick `watch` compares the death counter (`global.death`) with the tick before (`ModSet::ends_run`); a rise ends the run on that tick. The view's fixed-clock systems are the `view::SimTick` set, and `ModsPlugin` gates it with a run condition, so the sim stops ticking and a red "SUDDEN DEATH / Run over at tick N" banner (a child of the game camera, so it stays centred on the view) shows over the last frame. The quick-retry key or auto-retry starts again (below).
