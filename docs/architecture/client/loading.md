# The client: Loading card

Part of [the client](../client.md).

The loading card (`loading/`, #495; docs/product.md, Game select and loading) shows between game select and the run, built from the artboards `Loading.dc.html` and `LoadingUnranked.dc.html` (docs/design/mockups/m4) with the [UI](ui.md) kit.

- **When.** Every time the client opens a package, before the first tick. A retry does not show it. The package is already loaded when the window opens, so the card stays `loading::MIN_SECONDS` (1.5 s) and then starts the run by itself (the terminal says `loading: run started after 1.5 s`). The progress line fills over that time.
- **While it shows.** The sim does not tick (`SimTick` is gated by `loading::closed`), the game camera is off, the HUD is suspended (`hud::Suspended`, as on [results](results.md)), the backdrop takes the loading dim (`dim::LOADING`) and the pause key does not open the pause menu. Escape (or Start on a controller) leaves the run (`shell::leave`, [shell](shell.md)): back to the `--select` list, else the client quits; the card says `Esc quit` until the designed game select (#148). When the card closes, keys and client keys pressed on it are dropped, so nothing reaches the game. The results screen and the card each set `Suspended` and the game camera only when they open or close, so neither undoes the other.
- **Layout.** Laid out at the artboard's 1920×1080 and scaled to fit the window by its height (by its width below 1000 design px), the 760 px card centred 170 px from the top. The card has no shear; its key art strip is the backdrop's art (the package's key art, `screen.rs`) drawn over the card's top 240 px with the artboard's darkening towards the bottom.
- **Data.** `Info::new` reads the package's `game.toml` and the [stats](stats.md) book. Title (else the game id); `by` the creators with the `author` or `co-author` role (hidden without one); the map's name from `[[maps]]`, or `Ranked mode` / `Play original` for a package without maps; your PB on this map's board for this mode and these mods (`—` and `No clear yet` without one); the stage count of the map (its stages plus one).
- **Mods line.** The run's mod codes as mod pills. A ranked run says which mods it plays (`Sudden Death · ranked`, `No mods · ranked`). An unranked run adds the amber Unranked pill and the reason (`loading::standing`): Play original first (`Play original keeps your own stats only, so this run won’t reach the leaderboard.`), else the first mod that keeps it off the boards (`Slow motion 75% is a practice assist, so ...`, the speed from `--slow-speed`).
- **Fruit and tip.** The delicious fruit is the pause menu's (`pause::Fruit`: the package's `cherry` sprite, its first two frames, else our placeholder), drawn at twice its size and stepping frames every 320 ms (held still with reduced motion). The tip is one of `loading::TIPS`, picked by the clock; tips name only keys that cannot be rebound.
- **Hidden until they exist.** The star pill (difficulty ratings), the PB's global placement, the Global #1 column (its grid column stays empty) and the average clear time (online play, M7). The notes line under each number keeps its height, so the card stays the artboard's size.
- **Preview.** `iwbtg-client <package> --ranked --mods <codes> --loading-preview [--window WxH] [--screenshot <png>]` (hidden from `--help`) keeps the card up with the progress line at the artboard's 64 % and the artboard's sample PB (`38:12.46`). Use `--mods SL` for the unranked card. Any other `--screenshot` check skips the card, so screenshots of the HUD, pause menu and results still show the game.
