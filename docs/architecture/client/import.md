# The client: Import

Part of [the client](../client.md). Code: `import.rs`, and `package.rs` for opening the file (#36).

- **Opening an `.iwbz`.** `iwbtg-client <file>.iwbz` opens a package file like a package folder. `package::open` unpacks it with `iwbtg_format::iwbz::unpack`, which refuses anything a package may not hold and every zip bomb or path trick ([iwbz.md](../../format/iwbz.md)); the file already carries its engine pack, so nothing is read from `../_engines`.
- **The library.** An `.iwbz` the client opens (from the command line or the `--select` list, each time a run opens) is copied to `library/<id>.iwbz` in the data folder ([storage](storage.md); `%LOCALAPPDATA%\iwbtg-collection\library` on Windows), unless that copy is already the same file. A `--screenshot` check copies nothing. Game select (M6) will list the library; until then nothing reads it (the `--select` placeholder lists a folder given on the command line).
- **Drag and drop.** Dropping an `.iwbz` file or a package folder on the window opens it in the same window, from the `--select` list or during a run (`shell::start`, #841; [shell](shell.md)): a run in progress closes as when it is left (its replay and stats are finished on `OnExit(Run)`, its entities and assets dropped) and the dropped package plays from its start. The client keeps every flag it started with (`--select`, `--mods`, `--ranked`, `--trace-mode`, practice, retry and the rest), since they live in app-level plugins and resources; leaving the dropped game goes back to the `--select` list, or exits when the client was started on one package. The window keeps its size; a game with another room size is letterboxed, as from the list. Something that is not a package, or a package with errors, changes nothing (the run or the list goes on): the console gets a warning with the full path and every error, and a notice ([ui](ui.md), `notice.rs`; "NOT OPENED", #648) shows for a few seconds with the file's name and why: "is not a game package", "could not be read: ...", "did not start: ..." (the package opened but its sim did not) or, for a broken package, how many errors it has (warnings left out) and the first one, `file:line:column: message`, cut at 100 characters. Every failed drop shows its own notice. Test: `shell::tests::a_drop_during_a_run_plays_the_dropped_package`, `a_broken_drop_during_a_run_changes_nothing` and `a_drop_on_the_select_screen_plays_it` send `FileDragAndDrop` to the headless shell app.
- **Double-click (file association).** Opening a file from the OS runs `iwbtg-client <file>`, which is the command-line path above. Registering `.iwbz` with the OS needs an installer, which comes with the release builds (M9): #647.
