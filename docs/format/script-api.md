# Script API (generated)

Generated by `iwbtg script api-docs` from the functions registered on the IWS engine (Rhai metadata); do not edit by hand. A test (`cargo test -p iwbtg-tools committed_docs`) fails when this file or `script/iws.d.rhai` is stale. The language and its limits are in [0001](../decisions/0001-script-language.md); the first-version overview is in [architecture](../architecture/sim/scripts.md#script-api-first-version).

`script/iws.d.rhai` holds the same list as Rhai definitions for the Rhai language server. Types: `float` is every number a script sees (the engine uses `only_i64`, so integers exist, but API numbers are floats), `int`, `string`, `array`, `map`, `Instance` (a handle to an object instance) and `?` (any value). A number parameter of a math function (`sin(?)`, `irandom(?)`) or of `set_alarm` is shown as `?` because it takes an integer or a float alike; anything else is an error. "can fail" means a bad argument or state stops the script with an error.

## Porting from GML

- **Division.** `/` on two integers gives a FLOAT, as in GML. Use `div` and `mod` for GML `div` and `mod`.
- **Comparisons.** `==`, `<` and the rest on floats are exact IEEE. GML compares with the runner's epsilon: use `gm_eq`, `gm_ne`, `gm_lt`, `gm_le`, `gm_gt`, `gm_ge` where the original compares reals. The load check warns about a raw float `==`.
- **Truthiness.** A number is not a condition. Use `gm_bool(x)` for GML's `x > 0.5` rule.
- **`with`.** There is none. `instances(kind_or_group)` returns an array that is a snapshot at call time; loop over it.
- **Implicit instance variables.** Variables are not implicit: write `this.hp`, not `hp`. An unset read is an error.
- **Draw logic.** Scripts do not draw; see 0001 for `late()`.
