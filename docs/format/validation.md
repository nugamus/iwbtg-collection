# Validation

Part of [format v0](v0.md).

`iwbtg pkg check <dir>` runs these steps in order. The client and the server run the same checks on load and refuse a package that fails. Output is either OK or a list of readable errors with file, line and column. A file that fails to load (an object whose script is missing, say) is reported once, in its own file; references to it from rooms, the manifest or views do not add a "not a kind" error. A name that no file defines is still reported as not a kind.

1. Every data file parses, with no unknown keys.
2. Every reference resolves: rooms, kinds, sprites, sounds, music, timelines, scripts, trigger names, warp targets, engine pack assets.
3. Numbers are in range, and limits hold (image size, instances per room, script size).
4. Masks build from every sprite; frame counts match the image width. A sprite with a `[collider]` table must match the mask built from its PNG alpha data with the table's explicit `alpha_tolerance`; a mask with nothing solid is `none`, not a box with no solid pixel. A sprite's `mask` alias resolves through its chain to a sprite's own masks, independent of file order; a self alias or a cycle is an error, and a per-frame target must cover every frame of the sprite that uses it. An optional `[render_bounds]` table must name its shape; `custom` bounds lie inside the frame and cover every solid collider pixel, and `collider` bounds need a solid collider.
5. Every script compiles under the IWS profile with strict variables. Event names and arities are valid. Every called function exists. String literals passed to the API resolve. Lints run: RNG draws or state changes in a right operand of `&&`/`||`, float `switch`, a real value as a condition (errors), and raw float `==`/`!=` (a warning). Details: [architecture](../architecture/sim/scripts.md#scripts).
6. `object_order` lists every kind used in the package.
7. The timing triggers of `[timing]` and of every map exist; `enter_room` rooms exist. Each `enter_room` room can be reached, or `pkg check` warns (a warning, since a room change the data does not show can still lead there; `iwbtg_format::reach`, #504). Reachable are the start rooms (`start_room`, `[engine].new_game_room`, the first room in room order and the `boot` room, where `game_restart` and the reset go, `[stripped].start` and every `stripped_start`) and every room a reachable room leads to: a `room` param (`room_to`, the per-edge rooms of `edge_warp`) or a text param that is a room id (a scripted kind's `roomTo`), on a placed instance or an `on_create` `spawn` there, the instance's params over its kind's; the room a cut room is cut to. The rooms named by the params of a kind no room places or spawns (only a script or a spawner creates it) count as start rooms. Scripts lead on too (#731): a room placing or spawning a kind whose script passes a room literal to `room_goto` leads to that room, and one whose kind's script calls `room_goto_next` or `room_goto_previous` leads to the next or previous room in room order. A kind whose id a present kind's script passes as a literal to `instance_create` is present in that room too, and so on for the kinds it creates (#751). The `room_goto` literals of a kind no room places count as start rooms; its next and previous calls add nothing past the rooms such a creating kind is in, as the room it runs in is unknown. `[stripped]` and every `stripped_start` resolve: rooms, kinds and instance names exist, and the ranked start room is not cut. A kind whose classes match two collision handlers of another kind (its `collides_with`, the kid's `events.collisions`) that are equally specific makes `pkg check` warn (`iwbtg_format::ties`, #737): the sim runs one handler per pair, the matching class with the lowest `ClassMask::generality` (`block` last, `solidblock` next, every other class first), and breaks a tie by handler order, while GM runs the nearest parent's event; classes carry no parent order to settle it (sim register C8).
8. Manifest fields are present: creators, source URL, permission status, and a `[[third_party]]` entry for every file that needs one.
