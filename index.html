Reproduce this page

From the client repo: python -I progress/generate.py reads the committed data.json, the per-game front-matter and an optional progress/exporter.json. python -I progress/generate.py --gh --history refreshes phase counts from GitHub and appends a history point. The same command runs in .github/workflows/progress.yml and publishes to GitHub Pages. Exporter schema and commands are in progress/README.md.
